# Day 12: Assessment 1 — Core Java Checkpoint Deliverables

## 1. Overview
* **Assessment Type:** Core Java Checkpoint (Assessment 1)
* **Scope:** Integration of concepts from Days 1 through 11 (OOP design, collections, exception handling, generics, memory management, streams).
* **Practical Implementation:** 3-hour console application implementing 2 core e-commerce flows for the fashion store backend.

## 2. Implemented Core Flows
* **Flow 1: Catalog Browsing & Variant Filtering**
    * Displays available apparel and accessory items stored in collections.
    * Filters catalog items dynamically using Java 8 Streams and Predicates based on category and price constraints.
* **Flow 2: Cart Management & Checkout Processing**
    * Handles item additions to a virtual shopping cart with stock validation.
    * Implements custom exception handling (`InsufficientStockException`) to catch inventory shortages gracefully and finalize order billing.

# HCL Java Training - Daily Tasks

This directory contains the progressive daily task implementations completed as part of the HCL Java training curriculum.

| Day       | Topic / Module | Core Concepts Covered | Key Implementation Files |
|:----------| :--- | :--- | :--- |
| **Day 1** | System Info & Environment | JVM validation, extracting system properties and OS details | `PlatformInfo.java` |
| **Day 2** | Arrays & Type Casting | Multi-element data structures, array traversal, safe numeric conversions | Array utility scripts |
| **Day 3** | Control Flow & Secure Loops | Conditional branching (`if-else`, `switch`), loop controls (`break`/`continue`) | ATM simulator workflow |
| **Day 4** | OOP & Encapsulation | Private fields, getters/setters, constructor chaining (`this()`), static tracking | `BankAccount.java`, `BankApp.java` |
| **Day 5** | Inheritance & Polymorphism | Abstract classes, interfaces (`Refundable`), runtime polymorphism | `Payment.java`, `CardPayment.java`, `UpiPayment.java` |
